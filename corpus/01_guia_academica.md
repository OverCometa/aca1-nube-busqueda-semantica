# Guía didáctica de acompañamiento académico

## Propósito y alcance
Este manual propone un procedimiento de acompañamiento académico para un prototipo universitario. Es elaboración propia de Over Santiago Cometa Hernández para ACA 1; no es un reglamento de CUN ni un protocolo institucional aprobado. Se apoya conceptualmente en la gestión integral de la permanencia descrita por el Ministerio de Educación Nacional (MEN, 2023).

## Tutorías y dificultad en asignaturas
Cuando un estudiante solicita ayuda porque no comprende una asignatura, el primer paso propuesto es precisar el tema que le resulta difícil y revisar las actividades pendientes con el docente. Una tutoría académica puede centrarse en resolver dudas conceptuales, practicar ejercicios y revisar criterios de evaluación. Conviene acordar una meta pequeña y verificable para la siguiente sesión. Este procedimiento es una propuesta didáctica y no garantiza aprobar ni permanecer matriculado.

## Organización del estudio
Para una consulta sobre hábitos de estudio, se propone construir un horario semanal que incluya clases, trabajo independiente y descansos. El plan debe distribuir las tareas antes de las fechas de entrega y reservar tiempo para solicitar retroalimentación. El seguimiento puede registrar tareas realizadas, dudas pendientes y la siguiente acción acordada. No se recomienda interpretar la falta de tiempo como una falla moral del estudiante.

## Seguimiento académico y datos
En el dataset UCI existen cantidades de asignaturas inscritas y aprobadas durante el primer semestre. Estas variables permiten describir avance académico en la muestra portuguesa. La relación con este manual es temática: no existe evidencia de que esos estudiantes recibieran las tutorías propuestas. Los registros no corresponden a CUN ni sirven para asignar sanciones, diagnósticos o beneficios individuales en Colombia.

## Uso en el buscador
Preguntas como «¿Cómo organizar el estudio semanal?» o «¿Qué acompañamiento académico se puede proponer cuando una asignatura resulta difícil?» deben recuperar este manual. El resultado del buscador debe mostrar el fragmento y su procedencia. Si el documento no contiene una respuesta, no se debe completar la información con reglas inventadas.
